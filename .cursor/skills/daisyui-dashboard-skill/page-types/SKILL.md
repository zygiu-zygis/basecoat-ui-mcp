# Page Type Router
Analyze the design request, identify the page archetype, and route to the corresponding layout file. Do NOT generate UI components or structures.

## Workflows
Match the prompt to an archetype below. Upon matching, halt execution and transition context to the target file:

- `dashboard.md` *(Extract: Dashboard)*
- `auth.md` *(Extract: Auth)*
- `reading-views.md` *(Extract: Reading Views, documentation)*
- `settings.md` *(Extract: Settings)*
