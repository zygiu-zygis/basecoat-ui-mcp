# Page Type Router: Basecoat Archetypes

Analyze the design intent, identify the macro layout archetype, and route to the corresponding specification file.

## Workflows
Match the incoming requirement to an archetype below:

- `dashboard.md` *(Executive, Analytics, Operations, and Financial Dashboards; 12-column responsive grid, multi-dashboard variance)*
- `settings.md` *(Workspace Settings, Profile & Preferences, Tabbed Panes, Danger Zone isolation)*
- `auth.md` *(Authentication Split-Screen, Sign In, Sign Up, Password Recovery, Hero Value Props)*
